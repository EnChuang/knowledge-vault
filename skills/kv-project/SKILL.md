# kv-project — Project 筆記

Canon：`Project_rules.md`。前置：AGENTS 啟動前置；寫入前須有 MOC（或同次建最小 MOC）。**例外**：`配色查詢表.md` → **kv-palette**（§13）。

## §2 體裁分流

| 類型 | 體裁 |
|------|------|
| **非 Ebook 知識筆記** | **科普掃讀體**（預設） |
| **Ebook §12** | 公式＋註解；見下 §12 |
| MOC／日誌／MEMORY／配色／scaffold | 冷寫例外 |

### 科普掃讀（非 Ebook）

讀者只讀此檔掌握約 **80%**；像**投影片＋知識貼文**，可掃可滑。

| 目標 | 要求 |
|------|------|
| 自足 | 跨篇只在開頭／結尾 |
| **可掃讀** | 分鏡標題；短句；表／步驟優先 |
| 可滑完 | 單段宜 ≤4 行；禁長文牆 |
| 去噪 | 無導流 |

**骨架**：一句命題 → **本篇 30 秒**（3–5 條）→ 為什麼要懂（短）→ 分鏡展開（表卡為主、卡點一句譬喻）→ **記住這 N 點** → 延伸 → 自測。

**寫作前四問**（非例外檔）：

1. 有「30 秒帶走」嗎？  
2. 滑過標題能抓架構嗎？  
3. 卡點有一句譬喻嗎？  
4. 收束 3 點清楚嗎？  

用戶明示「長文／論述」該次可改走段落敘事。

## §3 讀者自測

1. **8–12 題**（緊扣核心）；Ebook §12 → **10 題**  
2. 僅讀正文作答  
3. 答不出 → 補正文 → 重測；Ebook → 10/10  
4. 答案可寫入 `<details>` 或「讀者自測答案」區  

## §4 命名

檔名＝`title`＝wikilink。禁 `討論`、`草稿`、純日期。Ebook：`{章號} · {章標題}.md`。

## §5 卡點譬喻

卡點一句譬喻 → 一句收斂；全文至少 1 則（非 Ebook）。

## §8–§9

分段：未請寫入只草稿。標籤無空格：`AI/Harness`。

## §12 Ebook 蒸餾（預設）

**`Source/Ebook/` 且用戶未另指定 → 必用。不套科普骨架。**

銜接 → `本章只記這幾件事`（≤5）→ `公式與註解` → `實務一句` → 自測 10 → 答案 → `<!-- Exam: 10/10 pass -->`
